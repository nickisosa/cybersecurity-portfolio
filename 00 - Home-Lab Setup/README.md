# Cybersecurity Home Lab

## Project Overview

I created a cybersecurity home lab using Oracle VirtualBox and Kali Linux to develop practical cybersecurity, Linux administration, and digital forensics skills.

This lab serves as a dedicated environment for hands-on learning, technical troubleshooting, security exercises, and future cybersecurity portfolio projects.

## Implementation Summary

- Installed and configured Oracle VirtualBox.
- Verified the integrity of the Kali Linux download using SHA-256.
- Configured virtual machine hardware and network settings.
- Created a personalized Linux user account.
- Configured and verified administrative privileges.
- Changed default credentials.
- Completed a full system upgrade.
- Verified system resource availability.
- Implemented basic system hardening measures.
- Configured a temporary read-only shared folder.
- Investigated and resolved permission-related issues.
- Revoked unnecessary access after completing file transfers.
- Created virtual machine recovery snapshots.

## Troubleshooting Experience

| Issue | Resolution |
|---|---|
| Incorrect user account selected | Verified the intended user identity. |
| Shared folder permission denied | Investigated and corrected group membership. |
| Incorrect username entered | Corrected the username and verified the command. |
| Group membership changes | Refreshed the login session. |
| Unable to unmount shared folder | Executed the command with elevated privileges. |

## Lessons Learned

Throughout this project, I strengthened my understanding of virtualization, Linux administration, system security, and troubleshooting.

One of the most valuable lessons was learning to investigate technical issues by reviewing error messages, verifying configurations, and identifying the underlying cause before implementing a solution.

I also gained practical experience applying the principle of least privilege by temporarily granting permissions and revoking them once they were no longer needed.
