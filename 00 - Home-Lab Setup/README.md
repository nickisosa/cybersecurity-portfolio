# Cybersecurity Home Lab Setup

This folder contains documentation related to the planning, deployment, configuration, and security of my cybersecurity home lab using Oracle VirtualBox and Kali Linux.

The home lab was established to provide a controlled environment for hands-on learning, cybersecurity exercises, technical troubleshooting, and digital forensics practice.

The setup focuses on virtualization, Linux administration, file integrity verification, system hardening, access control, network configuration, resource management, and system recovery.

This folder includes planning documentation, supporting screenshots, troubleshooting records, verification results, and a final home lab report.

The purpose of this home lab is to establish a strong technical foundation for my Python and hands-on cybersecurity projects while providing an environment that can expand as my 
knowledge and skills develop.

All security exercises are conducted ethically and within authorized environments.
