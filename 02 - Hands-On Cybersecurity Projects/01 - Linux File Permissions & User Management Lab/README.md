# Project 01 - Linux File Permissions & User Management Lab

**Project Status:** In Progress

## Project Overview

This project focuses on practicing Linux system administration, user management, file permissions, group-based access control, and file integrity verification through a simulated technology company called Royall Technologies.

The company consists of six fictional employees across three departments: Information Technology (IT), Human Resources (HR), and Finance.

## Project Objectives

- Develop Linux command-line skills.
- Create and manage user accounts and security groups.
- Configure file ownership and access permissions.
- Implement the principle of least privilege.
- Perform file integrity verification through hashing.
- Test and verify security configurations.
- Develop technical troubleshooting and documentation skills.
