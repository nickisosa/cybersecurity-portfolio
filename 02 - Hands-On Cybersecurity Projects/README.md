# Hands-On Cybersecurity Projects

This folder contains my practical cybersecurity projects designed to strengthen my technical skills through hands-on learning in controlled and authorized lab environments.

These projects focus on Linux and Windows administration, user and group management, file permissions, access control, network security, PowerShell, Active Directory, 
and security investigations.

Each project will include planning documentation, implementation procedures, supporting evidence, troubleshooting records, verification results, and a final project report.

The purpose of these projects is to apply cybersecurity concepts to realistic scenarios while developing the technical knowledge, problem-solving abilities, and investigative
skills necessary for a career in cybersecurity and digital forensics.

All security exercises are conducted ethically and within authorized environments.
